# cs_fundamentals

CS 전공 지식을 직접 설명하고 구현하며 정리하는 학습 기록입니다.

## 공부 방식

1. 교재의 한 단원을 읽는다.
2. 책을 덮고 핵심 개념을 내 말로 설명한다.
3. 책과 비교해 고친 뒤 커밋한다.

## 구조

| 폴더 | 내용 |
